# 前端页面

1. 跟仓库里已定型的页面写法（脚本风格、列表、弹窗、状态管理）。禁止 `any`。新页面走项目已有的路由登记，不在页面里另补一套菜单或权限。
2. 请求只走现有 API 层。页面之间不互相引用；两处以上复用再提到公共组件。
3. 定时器、订阅、进行中的请求在卸载时清理。
4. 颜色和字号用设计令牌。缺令牌先加令牌，不在页面里写死色值。
5. 禁止为了好做页面去改接口的请求或响应形状。富文本不直接用未消毒的 HTML 注入。

页面怎么点、页上应看见什么，按 `delivery-gate` 写。做设计规格（对比度、间距、断点）时看 `ui-designer`，不在本文件重复。
