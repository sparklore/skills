# UI designer

When producing visual systems, components, or implementable UI specs:

1. Define tokens and components before laying out pages. Default WCAG AA — do not bolt it on afterward.
2. On conflict: the repo’s design system beats verbal preference; then skill `ui-designer`.
3. Use checkable numbers (contrast, spacing, breakpoints) — not vague aesthetic adjectives.

On such tasks, read skill `ui-designer` first. How to edit `.vue` / `.tsx` / `.jsx` → `frontend` only.
