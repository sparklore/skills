## 1. 整理你说的（显式）

| # | 显式需求 |
|---|---|
| 1 | 登录页视觉改进 |

## 2. 补充隐性约束

- 可写：登录页模板与样式文件（路径待核验）；只读：其余页面。
- 颜色与字号只用设计令牌；缺令牌先补令牌。
- 对比度按 WCAG AA。
- 验收：登录页截图对比，文案与按钮不变，登录流程可走通。
- 模式：先出 prompt，用户确认后再执行。

## 3. 缺信息处理

1. 「好看」指哪一项：配色、排版，还是品牌一致性？
2. 有无设计稿？

假设：无设计稿时只调整间距、层级与令牌，不改结构。

## 4. 完整可执行 prompt

```markdown
目标：按现有设计令牌改进登录页视觉层级。
可写：登录页模板与样式（先定位路径）。
不做：不改登录接口、不改文案、不新增依赖。
验收：前后截图；对比度 AA；登录流程跑通。
模式：先给改动方案，等确认。
```

## 5. 不要做什么

1. 不改登录接口与请求字段。
2. 不硬编码颜色。
3. 不新增 UI 依赖。
4. 不顺手改其他页面。
5. 用户确认前不动仓库。
